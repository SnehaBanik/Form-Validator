# Form Validator

A simple and responsive form validation project built using **HTML, CSS, and JavaScript**.

The project validates user inputs such as email, password, and confirm password and provides clear validation feedback.

## 🚀 Features

- ✅ Email format validation
- ✅ Password validation
- ✅ Confirm password matching
- ✅ Password strength checking
- ✅ Show/Hide password functionality
- ✅ Error messages for invalid inputs
- ✅ Success message for valid inputs
- ✅ Responsive design
- ✅ Clean and simple user interface

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the webpage
- **CSS3** – Styling and responsive design
- **JavaScript** – Form validation and interactivity
